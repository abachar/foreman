# Code audit — 2026-08-30

Full read of the codebase (~27,000 lines, 209 Swift files), every finding verified in context; git output
behaviors verified empirically against git 2.43. Finding IDs below (`C*`, `M*`, and per-domain minors) are
referenced by the fix commits that follow this document in the same PR.

## 1. Architecture & overengineering

**Overall verdict: the codebase is remarkably disciplined — the problem is not overengineering, it is
lifecycle bugs.** The AGENTS.md rules (no single-implementation protocol, no EventBus, no speculative
abstraction) are respected almost everywhere: injection via closure-bearing structs (`PanelDescriptor`,
`PaletteSource`), pure logic in `nonisolated static` tested without UI (`StatusParser`, `TextEditing`,
`ConnectionLifecycle`, `Folding`…), native components used as-is (`NSSplitViewController`, `NSToolbar`,
`NSOutlineView` with no hand-rolled diffing, NSTextFinder, `NSDocumentController` for recents), typed
`throws` throughout, `Mutex`, `isolated deinit`, signposts. The few hand-rolled mechanisms (center split
tree, shortcut dispatch through an `NSEvent` monitor, `LineNumberRulerView`, the `.pgpass` parser) are
justified by a documented, dated constraint.

The real deviations, all small but real:

- **`SecretStore` violates the house rule** "no `Fake…` unless a plain value or closure cannot do the job"
  (`Workspace/SecretStore.swift:10,82-96`): `InMemorySecretStore` exists only for tests. A 3-closure struct
  (`read/write/delete`) removes the protocol and the `any SecretStore` existential.
- **`WorkspaceConfig` round-trips JSON four times per load** (`WorkspaceConfig.swift:69,96-101,118`).
  Negligible cost but accidental complexity; a `Sendable` `JSONValue` enum (a partial one already exists in
  `ThemeService+Tokens.swift:379`) would flatten the pipeline.
- **Write-only subscripts with `get { nil }`** in `Tokens.applying` (`App/ThemeService+Tokens.swift`):
  ~60 lines of string→property switching that a `[String: WritableKeyPath<Tokens, _>]` table replaces.
- **`TerminalService.events()` is a mini multi-subscriber bus** (`Terminal/TerminalService.swift:46-54`) for
  exactly two consumers.
- **The same timeout race is written twice** (`Postgres/PostgresClient.swift:186-201` and
  `PostgresFeature+Query.swift:158-172`); `PostgresConnection.Configuration` construction is duplicated
  between `establish` and `cancelRunning`.
- **Four independent variants of the path-containment check** (`ExplorerOperations.isInside`,
  `RunCatalog.isUnder`, the raw `hasPrefix` in `AgentsFeature.icon:167`, `AgentMention.relativePath`) — and
  none is applied where it matters most (see M1).
- **Structural weak point in Editor**: view lifecycle is split three ways (SwiftUI `EditorTabView`, the
  layout's cached `AnyView`, the coordinator-owned `NSScrollView`). That hybrid produces C1 and M4.
- **`Folding.regions` re-parses the whole document from scratch every 300 ms** (`Highlight/Folding.swift:21-38`)
  while Neon already maintains an incremental tree for the same text.

## 3. Findings by severity

### Critical

- **C1 — Every closed editor tab leaks its whole text stack (two independent retain cycles).**
  `EditorTab.textCoordinator` is a strong reference never nilled (`Editor/EditorTab.swift:88`) and
  `Coordinator.tab` is a strong `let` (`EditorTextView.swift:158`) → tab↔coordinator cycle retaining the
  `NSScrollView` + `NSTextView` + `TextViewHighlighter` + full text. Independently, the bounds-change
  observer block strongly captures coordinator and tab (`EditorTextView.swift:76-83`) and NotificationCenter
  retains the block until a `removeObserver` that lives in an unreachable `deinit`.
- **C2 — Every closed workspace window leaks its whole layout graph.** The shortcut-monitor context closure
  captures `LayoutManager` strongly (`Layout/ZonesView.swift:27,54-60`); AppKit retains the monitor closure
  until `NSEvent.removeMonitor`, which only runs in `ShortcutRegistry.deinit`
  (`ShortcutRegistry.swift:85-89`) — unreachable, since AppKit → closure → context → `LayoutManager` →
  registry.
- **C3 — The stash list never parses.** `RefParser.stashFormat = "%gd%1f%s"` (`Git/GitRemote.swift:34`):
  `stash list --format` uses the pretty machinery, which requires `%x1f` and emits `%1f` literally
  (verified with git 2.43). `fields.count == 2` always fails; the stash UI is permanently empty. The test
  masks it because the fixture hand-feeds a real `\u{1f}` (`GitRemoteTests.swift:52-55`).
- **C4 — Restored agent tabs can never be started.** The Relaunch bar renders only for `.exited`
  (`Terminal/TerminalTabView.swift:37`) and `buttonAction` maps `.idle` → `.activate`
  (`Agents/AgentsFeature.swift:185-189`, pinned by a test). After an app relaunch every restored agent tab
  is a dead terminal with no start affordance; agents spec R8 promises the opposite. `RunFeature` correctly
  maps idle → `.relaunch`.
- **C5 — The git branches sheet is invisible to SwiftUI.** `GitFeature` is not `@Observable`
  (`Git/GitFeature.swift:8-9`) but `GitChangesPanelView` presents the sheet off `feature.branchSheetRepo`
  and renders `feature.branches` (`GitChangesPanelView.swift:40-64`). `showBranches` mutates that state with
  no invalidation (`GitFeature.swift:370-378`): the sheet opens only if an unrelated refresh happens to
  re-render, and the async branch load never repopulates an open sheet.

### Medium

- **M1 — Path traversal: persisted/config paths escape the workspace.** `Workspace.url(forPersistedPath:root:)`
  (`Workspace+Paths.swift:15-18`) rejects neither `..` nor checks containment after standardization.
  Consumed by editor-tab restore, agent icons, agent/run terminal cwd. A cloned repo shipping a crafted
  `.foreman/state.json` restores tabs on `~/.ssh/config` and roots terminals outside the workspace. The
  security rule in `architecture.md` ("every path… is checked to be under the workspace root") is enforced
  nowhere.
- **M2 — Blocking I/O on the cooperative pool, with a domino effect.** `resolveLoginEnvironment` blocks a
  pool thread with no timeout — a prompting `.zprofile` freezes git and the editor forever
  (`Workspace+LoginEnvironment.swift:31-32`). `GitCLI` blocks 2 threads per command
  (`GitCLI.swift:230-231,268-271`); parallel `discoverAndRefresh` saturates an 8-thread pool **and starves
  the timeout watchdog itself**: a hung git can never be SIGTERMed. Same shape in `FormatterLaunch` (3
  threads up to 61 s) and `QuickOpenIndex.build` (200k-file walk with no yield or cancellation check).
- **M3 — Main-actor stalls.** Synchronous Keychain + `.pgpass` reads in `PostgresFeature.resolvePassword`
  (`PostgresFeature.swift:152-169`, a `@MainActor` class); full-diff AttributedString rendering on
  `@MainActor` (`GitDiffModel.swift:164-242`); a 50,000-row TSV rebuilt **on every selection click** via
  `.copyable([tab.copyText])` (`QueryGridView.swift:36`); `NSImage(contentsOf:)` inside a `LazyVStack` body
  (`MarkdownPreviewView.swift:187`); O(document) gutter work per draw — `ensureLayout(documentRange)` plus a
  copy of all text above the viewport (`LineNumberRulerView.swift:76-91`).
- **M4 — The "changed on disk" guard is defused by a tab switch.** `.task(id: tab.url)` re-runs `load()` on
  each re-appearance, which re-reads the file and refreshes `modificationDate`
  (`EditorTabView.swift:41-43`, `EditorTab.swift:194-202`): dirty tab + external edit + tab switch → `⌘S`
  overwrites the external changes with no prompt. Bonus: every tab switch re-reads the file (up to 50 MB).
- **M5 — Keystrokes lost around saves.** A keystroke during `save`'s await is clobbered by
  `isDirty = false` (`EditorTab.swift:308-310`). `saveAll` silently skips dirty tabs whose view is detached
  (`EditorFeature.swift:524-535`); `confirmClose` closes them without asking (`EditorFeature.swift:574`).
- **M6 — State lost on Cmd-Q.** The only flush is `onDisappear` firing an unawaited detached `Task`
  (`App/WorkspaceView.swift:88-91`); no `applicationShouldTerminate`. A panel rearrangement followed by
  Cmd-Q within the 1 s debounce is lost; same window for scratch autosave.
- **M7 — Untrusted JS can launch arbitrary external URL schemes.** `BrowserTab.policy` routes every non-web
  scheme to `NSWorkspace.shared.open(url)` with no prompt, no user-gesture requirement, **including from
  iframes** (`Browser/BrowserTab.swift:77-84,165-167`).
- **M8 — The diff parser ignores `core.quotepath` escaping.** git emits `"a/sp ace/\303\251.txt"` for
  non-ASCII paths (verified); `gitPaths` splits on spaces and `stripped` does not unescape octals
  (`GitDiff.swift:245-267`) → garbled headers, wrong `cat-file` objects, wrong "Send to Agent" paths. Merge
  commits (`diff --cc`) render "No Changes" (`GitDiff.swift:174`).
- **M9 — Postgres connection lifecycle.** (a) `PostgresFeature` ↔ `PostgresSchemaModel` retain cycle
  (`PostgresFeature.swift:22` / `PostgresSchemaModel.swift:25`): the `isolated deinit` that closes the
  connection never runs. (b) The 600 s idle close is armed at query *start* only: an 11-minute query has
  its connection closed mid-stream (`PostgresClient.swift:206-213`). (c) Hiding the schema panel mid-query
  kills it (`panelDeactivated` hardcodes `isBusy: false`, `PostgresFeature.swift:230-236`). (d) Any config
  edit — even one not touching the postgres section — resets the model to disconnected/read-only while the
  session stays writable (`PostgresFeature.swift:86-90`, `PostgresModel.swift:21-35`).
- **M10 — Git history: filtered pagination drops commits** (the merged skip is applied to each per-field
  query, `GitHistoryModel.swift:31-34`) **and unfiltered pages are re-sorted by author date**
  (`GitLog.swift:88-98`), sinking rebased commits far below HEAD.
- **M11 — Layout focus desync.** `PanelManager.focusPanel` has **no callers**; `ZonesViewController.apply`
  re-asserts the modeled focus on every SwiftUI update (`ZonesViewController.swift:150,234-247`): a theme
  change yanks the keyboard out of a panel the user is typing in, and the shortcut monitor resolves scopes
  from the same stale state.
- **M12 — Case-only rename is not crash/collision safe.** On a case-sensitive volume with an existing
  target, or on a crash between the two moves, the file is stranded under an invisible
  `.X.foreman-rename` name; no rollback (`ExplorerOperations.swift:75-78`).
- **M13 — Search tool failures are silent.** stderr → `nullDevice`, exit status never inspected
  (`ContentSearch.swift:134,146-169`): an invalid regex or unreadable root shows "No results" instead of an
  error.
- **M14 — `snapshotTree` is a write with a read's budget**: `add -A` through the temp index hashes the whole
  dirty worktree but runs as `kind: .read` (30 s timeout, outside write serialization,
  `GitCLI.swift:53-58,159-166`).
- **M15 — Snapshot serialization on every body evaluation.** `.onChange(of: layout.snapshot())` JSON-encodes
  every tab payload on each root body pass (`WorkspaceView.swift:128`); the toolbar re-resolves and
  reassigns every icon on each update (`WorkspaceToolbar.swift:49-59`) — and `IconImage.resolve` **mutates
  the shared `NSImage(named:)` cache instance** without copying (`IconImage.swift:14-27`).

### Corrections to this audit

Two claims in the table above did not survive implementation and are retracted. Both were assertions about
code the audit did not read closely enough — the failure mode is the same one section 4 warns about, applied
to the audit itself.

- **R4 is wrong.** It claimed FuzzyMatch computes match ranges that `QuickOpenIndex.search` throws away, and
  cited `docs/architecture.md:83` ("ranges for highlighting") as evidence the library was chosen for them.
  The pinned dependency (ordo-one/FuzzyMatch 1.0.5, revision `8059251` per `Package.resolved`) exposes no
  such API: `topMatches` returns `candidate` + `ScoredMatch(score, kind)`, and `matchPositions` exists only
  as an internal `@usableFromInline` field of `ScoringBuffer`. `QuickOpenIndex` discards nothing it could
  keep, and the greedy walker in `PaletteItem.highlighted` cannot be replaced by library ranges at this
  version. The Unicode fragility of that walker (L3) is real and still open. Separately, the justification
  recorded at `architecture.md:83` describes a capability this version does not provide — worth a look when
  that line is next revisited.
- **R6 is not actionable as written.** `splitViewDidResizeSubviews` posts `NSSplitViewDividerIndex` for
  `setPosition(_:ofDividerAt:)` too, which `applyRoom`/`setThickness` call constantly, so it does not
  separate a user drag from the programmatic adjustments the current heuristic exists to reject;
  accessibility-driven resizes take the same path; and the bottom panel's split view is its own delegate,
  needing extra forwarding. The heuristic stays until someone can verify a replacement against a running
  window.

One finding was also narrower than stated: **G6** covers merge commits through `git show`, but a *conflicted*
file makes `git diff` emit `diff --cc` as well, so a conflict's diff tab still renders "No Changes". Reading
combined diffs properly (two prefix columns, `@@@` headers) is a feature, not a fix, and was left out.

## 4. Test strategy

**Methodology gap #1: fixtures encode the developer's assumptions, not the tools' real output.** C3 (stash
`%1f`) and M8 (quotepath) would have been caught immediately by **golden tests against a real `git` binary**
on a scratch repo (round-trip `RefParser`, `StatusParser`, `DiffParser`). Best return on investment.

Priority unit tests:

1. **Deallocation tests** — gap #2, would have caught C1, C2 and M9a: open/edit/close a tab → a `weak var`
   on `EditorTab`/`Coordinator` must go nil; a `LayoutManager` + monitor on a real `NSWindow`, close → the
   manager must die; same for `PostgresFeature`.
2. **Containment**: `url(forPersistedPath: "../outside")`, absolute paths, symlinks pointing outside
   (Explorer and markdown `isInside`) — pin the M1 fix.
3. **Editor concurrency**: keystroke during an injected slow `FileDocument.write` (`isDirty` must stay
   true); dirty tab + external write + tab switch + save → must still prompt; `saveAll`/`confirmClose` with
   a detached view.
4. **Git parsing**: quoted/octal-escaped paths, pure rename with no hunks, merge (`diff --cc`),
   `\ No newline` on one side only, subject starting with `diff --git `; filtered pagination with
   overlapping subject/author matches (no dropped SHAs); a malformed `2` record followed by its origin.
5. **`QueryValue`**: `money` at −1/−50/−100 cents, `timetz` +05:45, `interval` negative micros/positive
   months, `numeric` NaN, zero-dimension arrays.
6. **Pure decisions to fix then pin**: `buttonAction` idle → relaunch (the current test pins bug C4),
   "reserved by layout" banner after an override to a different key, `ThemeColor("#+ABCDE")`, `PgPass` with
   a trailing space in the password.
7. **Rates and bounds**: `FSWatchService` under a sustained sub-debounce stream (an emission must occur
   within a bounded interval), 10k-deep nested JSON through `Folding.regions`, two near-simultaneous config
   edits (newest wins).

Integration attention points: state flush on the quit path; invalid regex in the search panel (rg *and*
grep fallback) must surface an error; a Postgres query streaming past `idleLimit` and hiding the panel
mid-query; N > cores git commands with one hung child — the watchdog must still fire; terminal grace races
(exit during the 5 s window, borderline SIGINT-relaunch); `decidePolicyFor` from a subframe for `.system`
schemes; CRLF/BOM round-trip after indent/comment/save; UTF-16 columns (emoji) in `TextEditing` and
ripgrep's UTF-8→UTF-16 conversion.
