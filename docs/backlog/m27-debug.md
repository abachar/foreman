# M27 — Debug

Twelfth round driven by use (2026-10-17), after [M26](m26-library-sources.md), which it needs (a frame inside a library opens the library tab). The feature that separates a text editor with LSP from an IDE: a breakpoint, a paused program, its stack and variables, stepping — through the Debug Adapter Protocol, Foreman being the client of an adapter the user declares, as it is the client of a language server. Targets: a Spring Boot backend under Maven (`ccoe-backend`, `java-debug` hosted by `jdtls`) and Foreman itself (`lldb-dap`, which ships in Xcode).

Domain: [`debug`](../specs/debug/) — [`00-study.md`](../specs/debug/00-study.md) (R1–R12), a new folder `Foreman/Debug/` and a row in `specs/README.md` and `architecture.md` (27.1). **No dependency**: the DAP client is written (~600 lines, one sentence of justification in 27.1's commit body: the two Swift packages read on 2026-10-17 have no client session).

**Nothing is written under the workspace root**: breakpoints go to `state.json`; the adapter jar and the paths are the user's config.

Size: S < ½ an agent-day, M ≈ 1 day, L ≈ 2 days. Status: ⚪ to do · 🟡 in progress · 🟢 done.

## Definition of done

- On Foreman's Debug build: a breakpoint in `EditorFeature.open` stops the app launched from the ▶ menu; the panel shows the frames and the `tab` variable's fields on expansion; `f6` steps; ■ terminates it.
- On `ccoe-backend`: the backend runs from its command with JDWP, Foreman attaches, a breakpoint in a controller stops a request from the browser tab; stepping into a Spring method opens the library tab of M26 with the paused line; ■ leaves the backend running.
- Without a `debug` section: no panel, no 🐞, no shortcut, nothing in the log.
- `git status` of `ccoe` shows nothing new; `state.json` carries the breakpoints.
- Tests pass; `swift format lint --strict` passes; `architecture.md`, `config.md`, `shortcuts.md`, `specs/README.md` updated by the tasks that touch them.
