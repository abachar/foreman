# Decisions — debug

| Date | Decision | Rejected | Why |
|---|---|---|---|
| 2026-10-17 | **Foreman is a DAP client, never a debugger**: one adapter per extension in `config.debug`, declared, the way language servers and commands are ([00-study.md](00-study.md) R1) | Driving JDWP or `lldb` directly; detecting the adapter from the project | Every language has an adapter speaking the same protocol (`java-debug`, `lldb-dap`, `js-debug`); `run` R1 and `editor` R35's policy: declared in the config, nothing detected |
| 2026-10-17 | **A session is a command** of `config.commands` with a `debug` object, `arguments` passed verbatim to the adapter's `attach`/`launch` (R2) | A `launch.json`; Foreman's own argument names translated per adapter | The ▶ menu already lists the commands and the Run panel already hosts their output; `editor` R57 (settings verbatim) showed a translation table is a cost for every adapter and a surprise for the user reading the adapter's documentation |
| 2026-10-17 | **Attach first for Java** — the command starts Spring with the JDWP agent, Foreman attaches; launch with `resolveMainClass`/`resolveClasspath` is the last task (R3, M27 27.4–27.5) | Launch first | Attach reuses Run and the `SPRING_*` environment the `ccoe` config already carries and is enough to debug a backend on day one; launch needs the server's resolution and `runInTerminal` on top |
| 2026-10-17 | **The DAP client is written** (~600 lines: envelope, fifteen requests, six events, a session actor), on `JSONRPC`'s `DataChannel` framing and `LSPAny` for the verbatim arguments; no new dependency | `ChimeHQ/DebugAdapterProtocol`; `noellee/SwiftDAP` | Read on 2026-10-17: the first has eight files, three commits (the last "prepare for transfer", 2026-09-14), no release and the server-side `initialize` only; the second is the adapter side, alpha. Neither has a client session; the types are the small part |
| 2026-10-17 | **The client is developed against `lldb-dap` on Foreman's own Debug build**, Java second | Starting on `ccoe-backend` | `lldb-dap` ships in the selected Xcode, needs no install and no bundle, and a breakpoint in `EditorFeature` is checked without leaving the repository — the way the LSP client was developed against `sourcekit-lsp` (editor decision 2026-08-31) |
| 2026-10-17 | **Breakpoints in `state.json`, never in `config.json`** (R4); nothing of the domain written under `.foreman/` | A `.foreman/breakpoints.json` | The author will commit `.foreman/` to share the config; breakpoints are one machine's session, and `state.json` is already the file that never enters git |
| 2026-10-17 | **The paused line in `statusOrange` at the current line's alpha**, the breakpoint dot in `statusRed` (R4, R5) | Two new theme tokens | `design` R6: the status colours already say these two things, as they did for the diagnostics (editor decision 2026-08-31) |
| 2026-10-17 | **Xcode's keys** for the seven actions (R7) | VS Code's `f5`/`f9`/`f10`/`f11` | The author's other editor is Xcode on this machine; every key is free in `shortcuts.md` on 2026-10-17 |
| 2026-10-17 | **The Angular frontend in the browser is out of scope** | `js-debug` driving Chrome | It is launching a browser Foreman does not own; `browser` R1's page already has Safari's Web Inspector (browser decision 2026-08-28) |
