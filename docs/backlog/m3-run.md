# M3 — Run

M3 = **lancer les commandes de l'utilisateur** : la feature `run` (`Run/`), déclarée dans `config.json` (`commands`), lancée depuis la palette `cmd+r` ou le bouton **▶ Run**, un onglet terminal réutilisé par commande avec son état (bleu / vert / rouge). À la fin de M3, `cmd+r`, `bt`, `enter` ouvre `backend:test` dans le dossier du repo, `mvn test` tourne, l'onglet dit s'il a réussi, `cmd+.` l'arrête, relancer réutilise l'onglet, et tout survit à la réouverture du workspace en `idle`.

Domaines couverts : [`run`](../specs/run/) ; compléments `Palette/` (`opt+enter`), `layout` (couleur de badge `blue`). `TerminalService` est réutilisé **tel quel** (décision M2).

Colonne **Lib / natif** obligatoire (`AGENTS.md`). Colonne **Tests** : ce qui est testé, rien d'autre.

## Vérifié avant M3 (2026-08-27, sur le code de `main` ffbca52)

**`TerminalService`** (`Wraith/Terminal/TerminalService.swift`) — API réelle, aucune modification prévue :

- `spawn(command:cwd:env:kind:title:) -> TabID?` (`nil` si kind inconnu du layout) ; `view(for:)` à appeler depuis le `makeView` de la feature ; `restore(_:kind:title:command:cwd:env:) -> AnyView` (onglet `idle`, commande non lancée).
- `relaunch(_:) throws(TerminalError)` — **refuse silencieusement tant que l'onglet est `running`** (`guard !tab.isRunning`) et jette `.cwdMissing` si le dossier a disparu. `run` R7 (stop puis relance) se fait donc côté `Run/` : `signal(SIGINT, to:)`, attendre `.exited` sur `events()`, puis `relaunch`.
- `signal(_:to:)` → `killpg` ; `state(of:)`, `pid(of:)`, `tab(_:) -> TerminalTab?` (`state`, `isRunning`, `isMarked`, `isCwdMissing`).
- `events() -> AsyncStream<TerminalEvent>` : un flux par consommateur ; `started(id, pid:)`, `exited(id, TerminalExit)` (`.code(Int32)` | `.signal(Int32)`), `bell`, `activated`, `closed`. `publish` est appelé **après** `syncBadge` : un badge posé par la feature à la réception de l'événement écrase celui du service.
- `confirmClose(_:) async -> Bool` (alerte « *X* is still running »), `closed(_:)` (SIGHUP puis SIGKILL après 5 s) : à relayer depuis `CenterTabDescriptor`, comme `AgentsFeature`.
- Le badge d'onglet est posé par `syncBadge` (`running` → `.dot(.green)`, marqué → `.dot(.orange)`, sinon `.none`) via `layout.update(_:title:isDirty:badge:)`.

## Définition de fini (M3)

- `.wraith/config.json` avec `"commands": { "backend": { "test": "mvn test" }, ".": { "$env": { "FOO": "1" }, "echo": { "run": "echo $FOO && sleep 3", "cwd": "docs" } } }` : `cmd+r`, `bt`, `enter` → onglet `backend:test` dans `backend/`, process lancé immédiatement, point bleu ; fin → point vert (code 0) ou rouge (≠ 0), effacé en activant l'onglet ; `root:echo` tourne dans `docs/` avec `FOO=1`.
- Relancer depuis la palette ou ▶ Run : même onglet, process en cours arrêté (`SIGINT`) puis relancé ; `cmd+enter` → second onglet indépendant ; `opt+enter` → commande dans le presse-papiers.
- ▶ Run : menu par repo avec commandes, sous-titres et points d'état ; badge bouton bleu pendant un run, rouge après un échec ; sans `commands`, le menu montre l'exemple.
- `cmd+.` dans un onglet `run` → `SIGINT` ; second appui rapide → `SIGTERM` ; aucun `SIGKILL` ; `cmd+.` dans un onglet agent ou éditeur → rien.
- `cmd+w` sur un run qui tourne → confirmation ; fermer la fenêtre → une confirmation par onglet qui tourne.
- Rouvrir le workspace : onglets `run` recréés `idle`, même cwd, titre `repo:nom`, *Relaunch* disponible ; commande non lancée ; commande retirée de la config → onglet non restauré (kind inconnu), loggé.
- Modifier `commands` : palette, menu et raccourcis `run.<id>` à jour sans redémarrer ; onglets ouverts intacts.
- `xcodebuild test` couvre toutes les lignes « Tests » ; lint propre ; **aucune dépendance SPM ajoutée** ; `TerminalService` non modifié (hors ajout éventuel dans `ToolbarBadge`).
- `docs/specs/run` à jour ; `shortcuts.md` : lignes run 🟢.
