# M2 — Terminal + Agents

M2 = **héberger un process** : la surface terminal partagée (`Terminal/`, SwiftTerm) et la première feature qui l'utilise, `agents` (boutons de toolbar, un onglet par agent). À la fin de M2, un clic sur *Claude* ouvre un onglet plein écran où Claude Code tourne avec l'environnement du login shell, se ferme proprement, se relance, et survit à la réouverture du workspace en état `idle`. `run` (M3) réutilisera `TerminalService` sans le modifier.

Domaines couverts : [`terminal`](../specs/terminal/), [`agents`](../specs/agents/) ; dossier partagé `Terminal/` ; `ThemeService` complet (`terminal` R14) ; compléments `layout` (badge d'onglet, focus terminal).

Colonne **Lib / natif** obligatoire (`AGENTS.md`). Colonne **Tests** : ce qui est testé, rien d'autre.

## Vérifié avant M2 (2026-08-27)

**SwiftTerm** (lu sur le clone du dépôt, pas de mémoire) : dernier tag `v1.20.0` (2026-08-18), `swift-tools-version:6.2`, `swiftLanguageModes: [.v6]`, macOS 11+. Ce qu'on utilise et qui existe :

- `LocalProcessTerminalView` (`open class`, `Sources/SwiftTerm/Mac/MacLocalTerminalView.swift`) : `init(frame:font:options:)`, `startProcess(executable:args:environment:execName:currentDirectory:)` — **`currentDirectory` est un paramètre, aucun `chdir` à faire** (l'étude disait « après `chdir` » : corrigé) —, `process.shellPid`, `terminate()` (= `SIGTERM`), `processDelegate: LocalProcessTerminalViewDelegate` (`sizeChanged`, `setTerminalTitle`, `hostCurrentDirectoryUpdate`, `processTerminated(source:exitCode:)`).
- Bell : `nonisolated open func bell(source: Terminal)` sur `TerminalView` → surcharge dans une sous-classe ; `bellStyle` (`.none/.sound/.visual/.soundAndVisual`).
- Scrollback : `TerminalOptions(scrollback:)` (défaut 500), `clearScrollback()`.
- Apparence : `font`, `nativeForegroundColor`, `nativeBackgroundColor`, `caretColor`, `selectedTextBackgroundColor`, `installColors([Color])` (palette ANSI 16), `resetFontSize()`.
- Clavier : `keyDown` envoie tout `cmd+…` à `interpretKeyEvents` (donc `copy(_:)`/`paste(_:)` natifs) ; `optionAsMetaKey = true` par défaut ; souris : `allowMouseReporting`, liens `cmd+clic` natifs (`linkHighlightMode`).
- `environment` est un `[String]` `KEY=VALUE`.

**Machine de l'auteur** : `claude` (`~/.local/bin`) et `opencode` (`~/.opencode/bin`) dans le PATH du login shell ; `antigravity` absent (question ouverte `agents`).

**Ce que le layout n'a pas encore** : pas de badge sur un `Tab` (seulement `isDirty`/`isPreview`) ; `ZonesView` passe `isTerminalFocused: false` en dur ; `ShortcutScope.tab(kind:)` est exact, or les onglets terminal ont pour kind `agent.<id>` / `run.<id>` ; `Workspace` n'expose pas l'environnement du login shell.

## Ce qui attend un autre milestone

- `run` R7–R13 : M3, sur le `TerminalService` livré ici (`spawn`, `relaunch`, `signal`, `events`), sans changement d'API prévu.
- Explorer/git : rien ; un agent modifie des fichiers → FSEvents rafraîchit déjà l'arbre et les onglets (M1).

## Définition de fini (M2)

**Fait (2026-08-27)**, validé à l'usage par l'auteur. Ajouts hors DoD : Pi intégré, binaire Antigravity `agy`, icônes SVG (asset catalog + fichiers du workspace), `Tab.badge`, `ShortcutScope.terminal`, événement `activated`.

- Clic *Claude* : onglet `Claude` en < 100 ms, Claude Code démarre à la racine avec le PATH du login shell ; TUI complet (couleurs 24 bits, souris, redimensionnement, `ctrl+c` au process, `cmd+c`/`cmd+v` copie/colle, `esc` au process). Idem OpenCode.
- Reclic → même onglet ; clic droit → *Nouvelle session* et *Lancer dans …* ; `/exit` → surface figée `terminé · code 0` + *Relancer* ; clic bouton → relance dans le même onglet.
- Bouton et onglet portent un point quand l'agent tourne ; une bell sur un onglet inactif le marque ; activer l'onglet efface la marque.
- `cmd+w` sur un agent qui tourne demande confirmation ; confirmer arrête tout le groupe de process (aucun `claude` orphelin dans `ps`) ; `cmd+w` sur `exited` ferme sans question.
- Fermer/rouvrir la fenêtre : onglet `Claude` recréé, vide, `idle`, même cwd, *Relancer* ; commande non relancée ; cwd supprimé → bannière, *Relancer* grisé.
- `.wraith/config.json` : `agents.claude.command = "claude --continue"` pris en compte sans redémarrer ; `agents.foo = { "command": "…" }` ajoute un bouton ; `terminal.fontSize` change la police de toutes les surfaces et de l'éditeur.
- `cmd+k` efface le scrollback, `cmd+=`/`cmd+-` zooment, scrollback 10 000 lignes ; une surface `exited` ou inactive ne consomme pas de CPU (Activity Monitor).
- `xcodebuild test` couvre toutes les lignes « Tests » ; lint propre ; dépendance SPM ajoutée : SwiftTerm — rien d'autre.
- `docs/specs/terminal` et `agents` à jour ; `questions.md` de `terminal` vidé (version, VT, `cmd+c`) ; `shortcuts.md` : lignes terminal et agents 🟢.
