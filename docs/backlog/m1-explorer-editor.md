# M1 — Explorer + Editor

M1 = **read and edit**: the workspace's file tree on the left, highlighted editor tabs in the center, the markdown preview, `cmd+p` quick open and `cmd+shift+f` content search at the bottom. By the end of M1, Wraith replaces a simple editor for opening a README or a config; it does not host any process yet.

Domains covered: [`explorer`](../specs/explorer/), [`editor`](../specs/editor/); the shared folders `Palette/` and `Highlight/` (`architecture.md`).

The **Library / native** column is mandatory (`AGENTS.md`): what we use instead of writing. The **Tests** column: what is tested, nothing else.

## What is waiting for another milestone

- explorer R4 (greying out gitignored entries) and R15 (badges): `Git.statusChanges` only exists in M4. In M1, only the greying from the shared exclusion list is done; the subscription is added in M4 (a task noted in `m4-git.md`).
- editor R18 (gitignored entries in the quick open index): the same, M4. In M1 the index applies the shared exclusion list only.
- editor R9 (`Editor.fileRenamed`/`fileDeleted`) are shipped here, called by the explorer; git will reuse them.

## Definition of done (M1)

- `cmd+shift+e` shows the workspace tree in < 100 ms, collapsed; a `touch`/`rm`/`mv` in the terminal shows up in < 1 s; the expanded state survives a reopen.
- Click = preview, double click = pinned, `opt+click` = a new group; switching tabs selects the file in the tree.
- A `.swift`, `.ts`, `.json`, `.md`, `.sql`, `Dockerfile` open highlighted in < 100 ms; a binary and a 200 MB file give a message, never a freeze.
- Typing marks the tab `●`, `cmd+s` saves keeping the EOL and the encoding; a file regenerated by a build reloads on its own, or asks when modified; closing the window with a modified tab asks for confirmation.
- `cmd+f` searches, `cmd+opt+f` replaces; `cmd+shift+v` switches a markdown file to preview with no network request.
- `cmd+p` + `usrctrl` → `UserController.java` first; `cmd+shift+f` lists the occurrences grouped by file and opens at the line.
- Right-click: create, rename, delete (trash), reveal, copy the path.
- `xcodebuild test` covers every "Tests" line; lint clean; SPM dependencies added: SwiftTreeSitter, Neon, R11's `tree-sitter-*` packages, swift-markdown, FuzzyMatch — nothing else. **Done (2026-08-27)**: 13 grammars (sql in M5), Neon and SwiftTreeSitter on `main`, swift-markdown 0.8, FuzzyMatch 1.4.
- `docs/specs/explorer` and `editor` up to date; `editor`'s `questions.md` emptied (TextKit 2 and the grammars settled). **Done.**

Outside the DoD, added in use (2026-08-27): a line-number gutter (editor R6), the `panel` scope for shortcuts (`escape`, layout R22b), `cmd+k` without a chord, new file/folder through a sheet.

A package that does not compile under Swift 6 / Xcode 27 is **removed from R11**, not patched — **done (2026-08-26)**: `sql` removed (invalid manifest), coming back in M5; css/javascript/yaml pinned to exact versions (an upstream manifest bug on the scanner); Neon and SwiftTreeSitter on `main`.
- 1.13: **the fuzzy library** — **settled (2026-08-26): FuzzyMatch (ordo-one, 1.0.0, Apache-2.0)** rather than Ifrit. Ifrit is a port of Fuse (Bitap: edit distance, no boundary bonus), designed for free-text search; FuzzyMatch is an fzf/nucleo-style Smith-Waterman (camelCase/snake_case bonuses, prefix, consecutive characters, ranges for highlighting), Swift 6, zero dependencies — exactly the path scoring R17 asks for. Risk: a recent library (June 2026); the API we use is three calls, and a replacement would be local to `Palette/`.
- 1.6: `ThemeService` is born with `Highlight/` (the monospaced font, the role colors) and stays minimal until `terminal` R14 (M2) brings the full theme.
- 1.9: `editor.insertFinalNewline` is read from the `editor` section of `.wraith/config.json` (there is no global config any more, config decision 2026-08-26); the R8 spec is corrected in the PR.
