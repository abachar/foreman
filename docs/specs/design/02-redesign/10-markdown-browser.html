orders-api

Order management API for the back office. Spring Boot 3, Java 21, PostgreSQL 16, migrations with Flyway.

Run locally

  1. Start the database: docker compose up -d db
  2. Launch the API: ./mvnw spring-boot:run
  3. Open localhost:8080/admin/orders
./mvnw test        # unit and slice tests
./mvnw verify      # + integration tests
