# M3 — Run

M3 = **launching the user's commands**: the `run` feature (`Run/`), declared in `config.json` (`commands`), launched from the `cmd+r` palette or the **▶ Run** button, with one terminal tab reused per command carrying its state (blue / green / red). By the end of M3, `cmd+r`, `bt`, `enter` opens `backend:test` in the repo's folder, `mvn test` runs, the tab says whether it succeeded, `cmd+.` stops it, relaunching reuses the tab, and all of it survives reopening the workspace as `idle`.

Domains covered: [`run`](../specs/run/); complements to `Palette/` (`opt+enter`) and `layout` (the `blue` badge color). `TerminalService` is reused **as is** (M2 decision).

The **Library / native** column is mandatory (`AGENTS.md`). The **Tests** column: what is tested, nothing else.

## Verified before M3 (2026-08-27, on the code of `main` ffbca52)

**`TerminalService`** (`Foreman/Terminal/TerminalService.swift`) — the real API, with no modification planned:

- `spawn(command:cwd:env:kind:title:) -> TabID?` (`nil` when the kind is unknown to the layout); `view(for:)` to be called from the feature's `makeView`; `restore(_:kind:title:command:cwd:env:) -> AnyView` (an `idle` tab, the command not launched).
- `relaunch(_:) throws(TerminalError)` — **silently refuses while the tab is `running`** (`guard !tab.isRunning`) and throws `.cwdMissing` when the folder is gone. `run` R7 (stop then relaunch) therefore happens on the `Run/` side: `signal(SIGINT, to:)`, wait for `.exited` on `events()`, then `relaunch`.
- `signal(_:to:)` → `killpg`; `state(of:)`, `pid(of:)`, `tab(_:) -> TerminalTab?` (`state`, `isRunning`, `isMarked`, `isCwdMissing`).
- `events() -> AsyncStream<TerminalEvent>`: one stream per consumer; `started(id, pid:)`, `exited(id, TerminalExit)` (`.code(Int32)` | `.signal(Int32)`), `bell`, `activated`, `closed`. `publish` is called **after** `syncBadge`: a badge set by the feature when it receives the event overwrites the service's one.
- `confirmClose(_:) async -> Bool` (an "*X* is still running" alert), `closed(_:)` (SIGHUP then SIGKILL after 5 s): to be relayed from `CenterTabDescriptor`, as `AgentsFeature` does.
- The tab badge is set by `syncBadge` (`running` → `.dot(.green)`, marked → `.dot(.orange)`, otherwise `.none`) through `layout.update(_:title:isDirty:badge:)`.

**`Palette`** (`Foreman/Palette/`): `present(_ source: PaletteSource, over: NSWindow)`; `PaletteSource(placeholder:, results: (String) async -> Results, select: (PaletteItem, newGroup: Bool) -> Void)`; `PaletteItem(id:title: AttributedString, subtitle:)` + `PaletteItem.highlighted(_:matching:)`; `Palette.limit = 50`. Keys handled by `PalettePanel.sendEvent`: `↑↓`, `enter`, `cmd+enter` (`newGroup: true`), `escape`. **No `opt+enter`** (`run` R6: copy): to be added. Fuzzy: `FuzzyMatcher(config: .smithWaterman).topMatches(_:against:limit:)` (ordo-one **FuzzyMatch**, already used by `QuickOpenIndex`).

**Layout**: `ToolbarItemDescriptor(id:title:icon:placement: .trailing, kind: .menu(entries: () -> [ToolbarMenuEntry]))`; `ToolbarMenuEntry(id:title:subtitle:badge:perform:)`; `LayoutManager.register(toolbarItem:)`, `setBadge(_:on:)`, `register(tabKind:)`, `replaceHomeEntries(in:with:)`, `openTab`, `activate(_:in:)`, `model.owner(of:)`. `ToolbarBadge.BadgeColor` = `green | orange | red` — **no `blue`** (`run` R6b, R10). `ShortcutScope` = `global | tab(kind:) | panel | terminal`; `ShortcutRegistry.register` **refuses an id that is already registered** (a fault) and has no unregistration. A restored tab of an unregistered kind is ignored (`LayoutManager+State`).

**Config**: `WorkspaceConfig.section("commands", as:)`, `repos: [URL]` (existing folders only), `configChanges`; `Workspace.persistedPath(for:root:)` / `url(forPersistedPath:root:)` (config R10). The `password` key is already stripped by `Workspace` (config R11).

**Spec**: `run` R3b cited the global config removed by the config decision of 2026-08-26 → corrected in 3.1.

## Definition of done (M3)

**Done (2026-08-27)**, validated in use by the author. Fixes outside the DoD found during validation: focusing the palette's field (`cmd+p` too), `"root"` accepted as an alias for `"."`, the leading item of `NSMenuToolbarItem` hidden, `Workspace.configChanges()` per consumer (a single stream for four subscribers: a reload reached only one feature).

- `.foreman/config.json` with `"commands": { "backend": { "test": "mvn test" }, ".": { "$env": { "FOO": "1" }, "echo": { "run": "echo $FOO && sleep 3", "cwd": "docs" } } }`: `cmd+r`, `bt`, `enter` → a `backend:test` tab in `backend/`, the process launched immediately, a blue dot; on completion → a green dot (code 0) or red (≠ 0), cleared by activating the tab; `root:echo` runs in `docs/` with `FOO=1`.
- Relaunching from the palette or from ▶ Run: the same tab, the running process stopped (`SIGINT`) then relaunched; `cmd+enter` → a second, independent tab; `opt+enter` → the command in the clipboard.
- ▶ Run: a menu per repo with the commands, subtitles and state dots; the button's badge blue during a run, red after a failure; with no `commands`, the menu shows the example.
- `cmd+.` in a `run` tab → `SIGINT`; a second quick press → `SIGTERM`; no `SIGKILL`; `cmd+.` in an agent or editor tab → nothing.
- `cmd+w` on a running run → a confirmation; closing the window → one confirmation per running tab.
- Reopening the workspace: the `run` tabs recreated `idle`, the same cwd, the title `repo:name`, *Relaunch* available; the command not launched; a command removed from the config → the tab not restored (unknown kind), logged.
- Editing `commands`: the palette, the menu and the `run.<id>` shortcuts are up to date without a restart; the open tabs are untouched.
- `xcodebuild test` covers every "Tests" line; lint clean; **no SPM dependency added**; `TerminalService` not modified (apart from a possible addition to `ToolbarBadge`).
- `docs/specs/run` up to date; `shortcuts.md`: run rows 🟢.

## To decide during M3 (decisions expected)

- 3.1: **`run` R3b** — settled here: removed, replaced by "a single source, `.foreman/config.json`" (config, decision 2026-08-26).
- 3.3: **a blue tab badge** — proposal: add `.blue` to `ToolbarBadge.BadgeColor` (one line); `RunFeature` re-sets its badge on every event of its tabs, which overwrites `TerminalService`'s green/orange without modifying it. Rejected alternative: making the colors configurable in `TerminalService` (an abstraction for two callers who do not need it).
- 3.3: **a command removed from the config with a persisted tab** — proposal: not restored (an unregistered kind, the layout's existing behaviour), like a removed agent; no command in the payload. To be confirmed in use.
- 3.3: **the relaunch wait** (R9: 10 s) — proposal: `ContinuousClock`, giving up with a log + a banner in the tab; no automatic `SIGTERM`.
- 3.4: **"most recently launched first"** — proposal: an in-memory list per window (no field in `state.json`, no migration); to be revisited if the default order proves lacking in use.
- 3.4: **`opt+enter`** — proposal: an optional `PaletteSource.secondary` (`nil` for quick open) rather than a third parameter on `select`; `PalettePanel` distinguishes `option` on `return`.
- 3.5: **the scope of `run.stop`** — proposal: `.terminal` with a no-op outside `run.*` (one action, one row in `shortcuts.md`) rather than a `tab(kind: "run.<id>")` action per command (n registrations, and `ShortcutRegistry` has no unregistration). `shortcuts.md` moves the scope from `tab(run)` to `terminal`.
- 3.5: **the `run.<id>` shortcuts of a removed command** — they stay registered (there is no unregistration), the action does nothing and logs; the same policy as `agents.<id>`.
