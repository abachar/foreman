# M2 — Terminal + Agents

M2 = **hosting a process**: the shared terminal surface (`Terminal/`, SwiftTerm) and the first feature that uses it, `agents` (toolbar buttons, one tab per agent). By the end of M2, clicking *Claude* opens a full-screen tab where Claude Code runs with the login shell's environment, closes cleanly, relaunches, and survives reopening the workspace in the `idle` state. `run` (M3) will reuse `TerminalService` without modifying it.

Domains covered: [`terminal`](../specs/terminal/), [`agents`](../specs/agents/); the shared folder `Terminal/`; the full `ThemeService` (`terminal` R14); `layout` complements (tab badge, terminal focus).

The **Library / native** column is mandatory (`AGENTS.md`). The **Tests** column: what is tested, nothing else.

## Verified before M2 (2026-08-27)

**SwiftTerm** (read on a clone of the repository, not from memory): latest tag `v1.20.0` (2026-08-18), `swift-tools-version:6.2`, `swiftLanguageModes: [.v6]`, macOS 11+. What we use, and what exists:

- `LocalProcessTerminalView` (an `open class`, `Sources/SwiftTerm/Mac/MacLocalTerminalView.swift`): `init(frame:font:options:)`, `startProcess(executable:args:environment:execName:currentDirectory:)` — **`currentDirectory` is a parameter, there is no `chdir` to do** (the study said "after `chdir`": corrected) —, `process.shellPid`, `terminate()` (= `SIGTERM`), `processDelegate: LocalProcessTerminalViewDelegate` (`sizeChanged`, `setTerminalTitle`, `hostCurrentDirectoryUpdate`, `processTerminated(source:exitCode:)`).
- Bell: `nonisolated open func bell(source: Terminal)` on `TerminalView` → overridden in a subclass; `bellStyle` (`.none/.sound/.visual/.soundAndVisual`).
- Scrollback: `TerminalOptions(scrollback:)` (default 500), `clearScrollback()`.
- Appearance: `font`, `nativeForegroundColor`, `nativeBackgroundColor`, `caretColor`, `selectedTextBackgroundColor`, `installColors([Color])` (the 16-color ANSI palette), `resetFontSize()`.
- Keyboard: `keyDown` sends every `cmd+…` to `interpretKeyEvents` (so native `copy(_:)`/`paste(_:)`); `optionAsMetaKey = true` by default; mouse: `allowMouseReporting`, native `cmd+click` links (`linkHighlightMode`).
- `environment` is a `[String]` of `KEY=VALUE`.

**The author's machine**: `claude` (`~/.local/bin`) and `opencode` (`~/.opencode/bin`) are in the login shell's PATH; `antigravity` is missing (an open `agents` question).

**What the layout does not have yet**: no badge on a `Tab` (only `isDirty`/`isPreview`); `ZonesView` passes `isTerminalFocused: false` inline; `ShortcutScope.tab(kind:)` is exact, whereas terminal tabs have the kinds `agent.<id>` / `run.<id>`; `Workspace` does not expose the login shell's environment.

## What is waiting for another milestone

- `run` R7–R13: M3, over the `TerminalService` delivered here (`spawn`, `relaunch`, `signal`, `events`), with no API change planned.
- Explorer/git: nothing; an agent modifies files → FSEvents already refreshes the tree and the tabs (M1).

## Definition of done (M2)

**Done (2026-08-27)**, validated in use by the author. Additions outside the DoD: Pi built in, the Antigravity binary `agy`, SVG icons (an asset catalog + workspace files), `Tab.badge`, `ShortcutScope.terminal`, an `activated` event.

- Clicking *Claude*: a `Claude` tab in < 100 ms, Claude Code starts at the root with the login shell's PATH; the full TUI (24-bit colors, mouse, resizing, `ctrl+c` to the process, `cmd+c`/`cmd+v` copy/paste, `esc` to the process). The same for OpenCode.
- Clicking again → the same tab; right-click → *New session* and *Launch in …*; `/exit` → a frozen surface `finished · code 0` + *Relaunch*; clicking the button → relaunch in the same tab.
- The button and the tab carry a dot while the agent is running; a bell on an inactive tab marks it; activating the tab clears the mark.
- `cmd+w` on a running agent asks for confirmation; confirming stops the whole process group (no orphan `claude` in `ps`); `cmd+w` on an `exited` one closes without asking.
- Closing/reopening the window: the `Claude` tab is recreated, empty, `idle`, at the same cwd, with *Relaunch*; the command is not relaunched; a deleted cwd → a banner, *Relaunch* greyed out.
- `.foreman/config.json`: `agents.claude.command = "claude --continue"` is picked up without a restart; `agents.foo = { "command": "…" }` adds a button; `terminal.fontSize` changes the font of every surface and of the editor.
- `cmd+k` clears the scrollback, `cmd+=`/`cmd+-` zoom, the scrollback is 10,000 lines; an `exited` or inactive surface uses no CPU (Activity Monitor).
- `xcodebuild test` covers every "Tests" line; lint clean; SPM dependency added: SwiftTerm — nothing else.
- `docs/specs/terminal` and `agents` up to date; `terminal`'s `questions.md` emptied (version, VT, `cmd+c`); `shortcuts.md`: terminal and agents rows 🟢.
