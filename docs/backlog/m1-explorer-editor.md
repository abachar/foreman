# M1 — Explorer + Editor

M1 = **lire et éditer** : l'arbre de fichiers du workspace à gauche, des onglets éditeur colorés au centre, la preview markdown, le quick open `cmd+p` et la recherche de contenu `cmd+shift+f` en bas. À la fin de M1, Wraith remplace un éditeur simple pour ouvrir un README ou une config ; il n'héberge encore aucun process.

Domaines couverts : [`explorer`](../specs/explorer/), [`editor`](../specs/editor/) ; dossiers partagés `Palette/` et `Highlight/` (`architecture.md`).

Colonne **Lib / natif** obligatoire (`AGENTS.md`) : ce qu'on utilise au lieu d'écrire. Colonne **Tests** : ce qui est testé, rien d'autre.

## Définition de fini (M1)

- `cmd+shift+e` montre l'arbre du workspace en < 100 ms, replié ; un `touch`/`rm`/`mv` au terminal se voit en < 1 s ; l'état déplié survit à la réouverture.
- Clic = aperçu, double clic = fixe, `opt+clic` = nouveau groupe ; changer d'onglet sélectionne le fichier dans l'arbre.
- Un `.swift`, `.ts`, `.json`, `.md`, `.sql`, `Dockerfile` s'ouvrent colorés en < 100 ms ; un binaire et un fichier de 200 Mo donnent un message, jamais un gel.
- Taper marque l'onglet `●`, `cmd+s` sauve en conservant EOL et encodage ; un fichier regénéré par un build se recharge seul, ou demande si modifié ; fermer la fenêtre avec un onglet modifié demande confirmation.
- `cmd+f` cherche, `cmd+opt+f` remplace ; `cmd+shift+v` bascule un markdown en preview sans requête réseau.
- `cmd+p` + `usrctrl` → `UserController.java` en tête ; `cmd+shift+f` liste les occurrences groupées par fichier et ouvre à la ligne.
- Clic droit : créer, renommer, supprimer (corbeille), révéler, copier le chemin.
- `xcodebuild test` couvre toutes les lignes « Tests » ; lint propre ; dépendances SPM ajoutées : SwiftTreeSitter, Neon, les packages `tree-sitter-*` de R11, swift-markdown, FuzzyMatch — rien d'autre.
- `docs/specs/explorer` et `editor` à jour ; `questions.md` d'`editor` vidé (TextKit 2 et grammaires tranchés).

- 1.13 : **lib fuzzy** — **tranché (2026-08-26) : FuzzyMatch (ordo-one, 1.0.0, Apache-2.0)** plutôt qu'Ifrit. Ifrit est un portage de Fuse (Bitap : distance d'édition, pas de bonus de frontière), conçu pour la recherche de texte libre ; FuzzyMatch est un Smith-Waterman façon fzf/nucleo (bonus camelCase/snake_case, préfixe, consécutifs, ranges pour le surlignage), Swift 6, zéro dépendance — exactement le scoring de chemins demandé par R17. Risque : lib récente (juin 2026) ; l'API utilisée tient en trois appels, un remplacement serait local à `Palette/`.
- 1.6 : `ThemeService` naît avec `Highlight/` (police mono, couleurs de rôle) et reste minimal jusqu'à `terminal` R14 (M2) qui apporte le thème complet.
- 1.9 : `editor.insertFinalNewline` est lu dans la section `editor` de `.wraith/config.json` (il n'y a plus de config globale, décision config 2026-08-26) ; la spec R8 est corrigée dans la PR.
